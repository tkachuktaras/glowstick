# Code of Conduct

Glowstick is a free, open project. Everyone taking part in it (issues, pull requests, discussions, translations, reviews) should be treated with respect.

## Expected behavior

- Be respectful and constructive, including when you disagree.
- Assume good intent and give feedback on the code or idea, not the person.
- Keep discussions on topic.
- Credit others' work and respect licenses.

## Unacceptable behavior

- Harassment, insults, personal attacks or discrimination based on who someone is.
- Trolling, deliberately disruptive posts, or spam.
- Publishing others' private information without consent.
- Sexual content or imagery, and any threats.
- Anything else that a reasonable person would find unwelcome in a professional setting.

## Scope

This applies in all project spaces: the GitHub repository, issues, pull requests, Discussions, and any other channel used to talk about Glowstick. It also applies when someone represents the project in public.

## Reporting

Report conduct problems privately through [GitHub Security Advisories](../../security/advisories/new) and say that it is a conduct report. Include what happened, where, and any links or screenshots. Reports are read by the maintainer and handled confidentially. Please do not discuss a conduct report in public issues.

## Enforcement

The maintainer decides on a response proportionate to the problem. This can be a warning, a request to edit or remove content, a temporary block, or a permanent ban from the project's spaces. People who report in good faith will not be punished for it.
